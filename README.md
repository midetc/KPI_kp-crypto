# Криптосистема (Цезар + Тритеміус)

Студент: Михайлець Артем Миколайович, ТВ-33

## Запуск

```
pip install -r requirements.txt
python main.py
python -m unittest test_crypto.py
python make_zvit.py
```

Ключ для Цезаря за методичкою — номер у списку групи (**13**).
Тестове слово: **Алфавіт**.

## Режими

- Цезар — ключ: ціле число
- Тритеміус лінійний — `A,B`
- Тритеміус нелінійний — `A,B,C`
- Тритеміус гасло — текстовий рядок

Бінарні файли відкриваються як raw bytes і шифруються mod 256.
