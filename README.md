kp-crypto/

## Запуск

```
pip install -r requirements.txt

cd praktika1_cezar
python main.py
python -m unittest test_crypto.py
python make_zvit.py

cd ../praktika2_trytemius
python main.py
python -m unittest test_crypto.py
python make_zvit.py
```

КП1: ключ = номер у списку (**13**), слово **Алфавіт**.  
КП2: ключ `2,5` / `1,2,3` / гасло текстом.
